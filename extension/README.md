# 云创考勤洞察

Chrome MV3 插件，用于展示云创考勤日历、月平均工时、欠工时和异常日期。

## 安装试用

1. 打开 Chrome 扩展程序页面：
   `chrome://extensions/`
2. 打开右上角「开发者模式」。
3. 点击「加载已解压的扩展程序」。
4. 选择本目录：
   `C:\Users\suerwei\Documents\工时记录\extension`
5. 点击工具栏里的「云创考勤洞察」图标。

## 登录方式

插件支持两种登录：

1. **手动登录（默认）**：在当前 Chrome 用户里正常登录一次
   `https://yunchuang.talkweb.com.cn/user/login?redirect=/dashboard/analysis`，
   插件即可读取登录态刷新数据。
2. **后台自动登录（可选）**：在插件设置里填入工号 + 密码并开启“自动登录”，
   token 过期时插件会用本地 OCR 识别图形验证码，静默调用登录接口续期，
   全程无需手动操作、无需企业微信扫码。

主地址不可用时自动切换备用地址 `https://yunchuangwq.talkweb.com.cn`。

### 开启后台自动登录

1. 点击插件右上角 ⚙ 图标展开设置。
2. 填入工号（帐户名）和密码，勾选“启用后台自动登录”，点“保存”。
3. 点“测试登录”验证一次；提示“登录成功”即生效。

> ⚠️ **安全提示**：账号密码以明文保存在本浏览器的 `chrome.storage.local`，
> 任何能访问该 Chrome 用户资料的人都能读取。共用电脑请勿开启此功能。

## 登录态维持机制

云创 token 为固定 12 小时 JWT，无滑动续期，过期后须重新登录获取新 token。插件的自动处理：

- 后台每 30 分钟静默请求一次接口，保持当月缓存新鲜。
- token 过期且已配置自动登录时，插件在后台用工号密码 + 本地 Tesseract.js
  识别图形验证码，直接 `POST /auth/sys/login` 获取新 token（验证码识别偶尔
  出错会自动换一张重试，最多 6 次），全程无页面、数据不出本机。
- 未配置自动登录时，token 过期会明确提示，点“打开云创”手动登录一次即恢复。

### 本地验证码识别

`extension/vendor/tesseract/` 内置了 Tesseract.js v5 及英文语言包，OCR 完全离线运行；
识别在离屏文档（offscreen document）中进行，先做二值化去噪预处理再识别。

## 统计口径

- 非工作日不参与月平均工时。
- 当前日期不参与月平均工时。
- 全日请假不参与月平均工时。
- 半天请假按有效应出勤小时折算分母。
- 实际工时优先采用接口 `duration`。
- 欠工时采用接口 `missDuration`。

月平均工时：

```text
有效应工作小时 = sum(max(workLength - leaveDuration, 0))
有效工作日 = 有效应工作小时 / 8
月平均工时 = sum(duration) / 有效工作日
```
