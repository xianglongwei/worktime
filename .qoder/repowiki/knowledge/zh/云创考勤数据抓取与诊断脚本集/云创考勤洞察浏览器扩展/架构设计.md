基于 Manifest V3 的 Chrome 扩展，按职责拆分为三个脚本：
- `background.js`（service worker）：唯一持有网络请求逻辑，负责调用 `/attendance/human/rzAttendanceinfo/listByMonth`、通过 `chrome.storage.local` 缓存 `attendance:YYYYMM` 数据、向已打开的云创标签页发送 `COLLECT_YUNCHUANG_AUTH` 消息以刷新鉴权快照。
- `content.js`（注入到 `https://yunchuang.talkweb.com.cn/*`）：扫描 `localStorage/sessionStorage` 中匹配 token/authorization/access-token 等键名的条目，提取并回传 `YUNCHUANG_AUTH_SNAPSHOT` 给 background，供后续 API 请求复用。
- `popup.html/popup.js/popup.css`：用户交互入口，通过 `chrome.runtime.sendMessage({type:'GET_ATTANCE'})` 触发 background 拉取数据，本地渲染月度统计与日历网格；非扩展环境自动降级为 `demoAttendance()` 演示数据。
依赖方向单向：popup → background → content（反向仅用于 auth 收集），所有对外 I/O 集中在 background，避免 popup/content 直接访问 `fetch` 或跨域。
