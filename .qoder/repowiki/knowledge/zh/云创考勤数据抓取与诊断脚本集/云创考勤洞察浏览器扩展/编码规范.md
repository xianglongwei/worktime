- 通过 `chrome.runtime.onMessage.addListener` 统一注册字符串型 message type（如 `GET_ATTENDANCE`、`YUNCHUANG_AUTH_SNAPSHOT`、`OPEN_LOGIN`），并在函数末尾显式 `return true/false` 控制异步响应生命周期。
- 对后端返回的数值字段一律经 `Number(value)` + `Number.isFinite` 校验后归零，避免 NaN 污染统计计算。
- DOM 操作前通过 `document.querySelector` 将元素引用缓存在顶层 `els` 对象中，避免重复查询。
- 时间维度统一使用 `YYYYMM` 字符串作为 key 与 URL 参数，并通过 `toYearMonth` / `dateKey` 工具函数在 Date 与字符串之间转换。
