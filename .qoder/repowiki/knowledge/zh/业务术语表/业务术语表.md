### 云创考勤洞察
- 定义：本项目的正式名称，是一个 Chrome 扩展插件，用于在日历视图上展示云创系统的打卡时间、月平均工时、欠工时和异常日期统计。
- 别名：考勤洞察、云创插件

### 保活请求
- 定义：为防止云创系统服务端 token 过期而定期发送的轻量级 HTTP 请求，利用其滑动过期机制维持登录态有效。即使浏览器关闭重启，只要未超过服务端过期窗口，即可实现无感续期。
- 别名：token 保活、心跳请求

### 自动恢复链
- 定义：多层级的登录态恢复机制：第一层通过保活请求续期；第二层当保活失败时静默打开云创页面利用 SSO 会话重新签发 token；第三层当 SSO 也过期时提示用户手动登录。目标是实现'登录一次，长期无感'。
- 别名：登录态恢复、认证恢复

### 缓存回退逻辑
- 定义：当网络请求失败时，插件会检查本地是否有历史缓存数据，如果有则显示旧数据并隐藏错误信息。这是导致用户点击刷新后'没有任何反应'的直接原因——错误被静默吞掉，只显示昨天的缓存数据。
- 别名：离线缓存、降级显示

### 认证快照
- 定义：从云创页面中扫描 localStorage/sessionStorage 捕获的认证相关信息，包括 token 值和对应的请求头格式。保存键名为 `yunchuangAuth`，包含 headers、foundKeys 和 capturedAt 字段。
- 别名：auth snapshot、认证信息

### 滑动过期
- 定义：云创系统采用的 token 过期策略：服务端 Redis 中的 token 在有请求活动时自动续期，长时间无活动则在服务端失效。这与前端 localStorage 的本地过期时间不同，是'昨天登录今天失效'的根本原因。
- 别名：滑动失效、活动续期

### 有效应工作小时
- 定义：计算月平均工时的分母，公式为：sum(max(workLength - leaveDuration, 0))，即扣除请假时长后的实际应出勤时间。全日请假不参与计算，半天请假按有效应出勤小时折算。
- 别名：有效工作日、基准工时

### 异常记录
- 定义：考勤数据中标记为异常的记录，包括状态为'异常'、存在 exception 字段、missHours > 0、workTimeNormal 或 offWorkTimeNormal 为 false 的情况。用于统计缺勤、迟到早退等异常情况。
- 别名：异常考勤、问题记录
